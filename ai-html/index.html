使用前的安心坦白宣言

這東西跑在哪裡？需要辦帳號嗎？

完全不用！這是我在 GitHub 上建立的免費開源架構。你不需要申請任何開發者帳號，也不用填寫名字或 Email。你就像是借用我的廚房來為自己煮一碗專屬的麵，不需要懂怎麼蓋廚房。

會不會收集我的個人隱私資料？

零個資、零追蹤。所有你選擇的習慣、待辦事項與心情隨筆，預設全部安全地存在你**自己的手機瀏覽器（LocalStorage）**裡。若未來需要跨裝置同步，也是直接連回你**自己的 Google 雲端**，金鑰永遠在你手上。

這世界上真的有免費的午餐嗎？

老實說，架設網站、寫程式都有成本。但因為這是我自己每天也在用的工具，所以順便做出來跟大家分享。我不需要你的信用卡，如果你覺得好用，順手點點頁面上的小廣告或贊助連結，就能幫我貼補柴米油鹽；不點也沒關係，安心用、開心用最重要！

如果以後不想用了怎麼辦？

直接把手機桌面上的這個捷徑圖示像刪普通 App 一樣刪掉就好。拍拍屁股走人，完全不留負擔，也不會影響手機原本的運作。
