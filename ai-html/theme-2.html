把我的 myezlife 佈景主題釘選到桌面上

只需 3 秒鐘，它就會像原生 App 一樣安靜地待在您的手機桌面上，隨點隨開！

  1. 使用手機內建的 Safari 瀏覽器 打開本網頁。
  2. 點擊下方工具列的 「分享」按鈕（正方形帶有往上箭頭圖示 ⎋）。
  3. 在選單中向下滑動，點選 「加入主畫面」。
  4. 右上角點擊 「新增」，大功告成！桌面就會出現專屬圖示。

  2. 點擊右上角的 「選單」按鈕（三個點 ⋮）。
  3. 在選單中點選 「加到主畫面」 或 「安裝應用程式」。
  4. 點擊確認安裝，這個專屬佈景主題就會直接變成桌面捷徑！
