GOOGLE 雲端同步
GAS 雲端同步建置教學指南：
  1. 建立 App Script：前往 Google 雲端硬碟建立一個新的「Google Apps Script」專案。
  2. 貼上同步程式碼：將處理 JSON 資料存取的 `doGet` 與 `doPost` 腳本程式碼貼入專案中。
  3. 部署為 Web App：點擊右上角「部署」➔「新增部署作業」，選擇「網頁應用程式 (Web App)」。
  4. 設定存取權限：將「誰可以存取」設定為 「所有人 (Anyone)」 並完成部署。
  5. 貼上 Web App 網址：複製獲得的 Web App 網址並貼入下方輸入框，即可實現多裝置自動備份與同步！
